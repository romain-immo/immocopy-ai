⏱ 2 minutes chrono

Créez votre clé API Gemini
gratuitement

Suivez ce guide pas à pas pour obtenir votre clé API Google Gemini et commencer à générer vos posts immobiliers.

1

Rendez-vous sur Google AI Studio

Ouvrez votre navigateur et allez sur :

aistudio.google.com
💡 Vous avez besoin d'un compte Google (Gmail). Si vous n'en avez pas, créez-en un gratuitement sur gmail.com.
2

Connectez-vous avec votre compte Google

Cliquez sur le bouton de connexion et entrez votre adresse Gmail et votre mot de passe.

Se connecter avec Google
3

Cliquez sur "Get API Key"

Une fois connecté, regardez dans le menu à gauche et cliquez sur "Get API Key" ou "Clé API".

→ Get API Key (ou "Clé API")
4

Créez une nouvelle clé API

Cliquez sur le bouton "Create API Key" (ou "Créer une clé API").

+ Create API Key

Si on vous demande de sélectionner un projet, choisissez "Create new project" et donnez-lui un nom (ex: ImmoCopy).

5

Copiez votre clé API

Votre clé API apparaît — elle ressemble à une longue suite de lettres et chiffres. Cliquez sur l'icône pour la copier.

AIzaSy•••••••••••••••••••••••••• 📋
⚠️ Ne partagez jamais cette clé avec personne — c'est votre accès personnel et gratuit à l'IA.
6

Collez la clé dans ImmoCopy AI

Retournez sur ImmoCopy AI, et dans la barre latérale gauche, collez votre clé dans le champ "Clé API Google Gemini".

⚙️ Configuration

Clé API Google Gemini
Collez votre clé ici...
🎉

Vous êtes prêt !

Votre clé API est configurée. Vous pouvez maintenant générer vos posts immobiliers professionnels en 2 secondes.
